具体步骤

  1. 行程页顶部有三个视图可以切换：时间线（按天逐条看）、日历（一个月看全貌，日期下面顺带显示当天花了多少）、地图（每天的行程点用不同颜色标出来，点上面的日期图例还能只看那天的路线——图例可以左右滑动，行程天数多也不占地方）。
  2. 先在上面横向选一个日期，再点最下面的"添加行程项"，依次填时间、要做什么、地点（可以搜索或直接贴Google Maps链接）、备注，点右下角"✓"保存。
  3. 点已有的卡片会展开成编辑框——改完点"✓"保存，或者直接点卡片外面的空白处：标题填了就自动保存，标题还是空的就直接放弃，不会留下一条空行程项。
  4. 手机上用返回键也能收起编辑框，不会因此退出整个APP。
小技巧：紫色书签图标是"想去的地点"入口，规划行程时随时能从收藏清单里挑地方，不用重新搜索。

账怎么记

每一笔花费记下来，谁付的、算不算大家一起分，之后自动汇总。

具体步骤

  1. 记账页右下角"+"，先填金额和币种——用外币记账时，只要汇率簿里有对应汇率，会自动换算成本位币。
  2. 选一个分类（餐饮/住宿/交通…），选是"出行前"还是"途中"花的，选日期，写备注。
  3. 选付款人——谁先垫付的钱。
  4. 点"怎么分"，决定这笔钱是"大家分摊"（选平均或自定义金额）还是"个人开销"（不分摊给别人）。
  5. 还可以点"关联行程"，把这笔账跟具体某个行程项绑在一起，之后从行程页也能看到。
带小数的金额（比如509.60）现在会照实显示两位小数，不会被简化成整数——不用担心看着像存错了。

怎么分账结算

谁垫付了多少、谁该找补给谁，APP自动算出最少的转账笔数。

结算建议 · 还剩 2 笔

去结算
大大宝→爸爸爸RM176.64
去结算
谁付了多少
妈妈应收 RM466.68

具体步骤

  1. 分账页顶部"结算建议"会自动算出最少的转账笔数——不是每个人两两互转，而是合并成最少几笔，就能让大家都不亏不赚。
  2. 点"去结算"，展开的表单可以填结清金额（支持部分结清，比如先还一半）、日期、备注（比如"现金"还是"转账"）。
  3. 确认对方已经收到钱之后，点"确认已结清"，这笔就会从"还剩几笔"里划掉。
  4. 往下滚可以看"谁付了多少"——每个人垫付了多少、应该分摊多少，一目了然。
提醒：结清记录之后还能在下面的"结算记录"里找到、改金额/日期，或者撤销，不用担心手滑点错。

预算怎么看

设个总预算，或者按分类分别设，随时看还剩多少、有没有超支。

预算
33%还剩 RM3,354
RM1,646 / RM5,000
分类明细+ 加分类预算
餐饮RM380 / RM2,000
住宿现付RM890 / RM3,500

具体步骤

  1. 第一次进预算页会提示"还没设置整趟行程的总预算"——填个数字确认，圆环图就会跟着显示已用比例。
  2. 点"加分类预算"，可以单独给"餐饮""住宿"这些分类设上限，各自有独立的进度条。
  3. 记的每一笔账都会自动算进对应分类和总预算里，不用手动更新。
  4. 想改总预算，点"改总预算"；不想再追踪了，点垃圾桶图标删除（已经记的账不受影响）。
预算只是提醒自己，超支也不会锁住记账功能——该记还是能记，只是进度条会变红提醒一下。

想去的地点怎么用

刷到想去的餐厅/景点先存起来，不属于任何一趟具体行程，规划任何新行程都能用。

入口（两处都可以）
我的行程 🔖 想去的地点
时间线 🔖
顶层"我的行程"列表（深色页头）/ 进了行程后"行程"tab头部
想去的地点 + 新增
一兰拉面 涩谷店○ 还没去
朋友推荐，记得点半熟蛋
还能收藏更多地点…

具体步骤

  1. 入口有两处：顶层"我的行程"列表页右上角的胶囊按钮；或者进了具体某趟行程后，行程tab头部的紫色书签图标（不管切到时间线/日历/地图哪个视图都在）。
  2. 点"新增"，填地点名字（可以搜索定位，或者贴Google Maps链接）和备注。
  3. 安排行程时，"添加行程项"表单上方有"从想去的地点里选一个"，选一条会自动带上名字和坐标，不用重新搜索。
  4. 安排行程时，如果清单里有地点离当天已排的行程比较近，时间线顶部会自动出现提示卡，点"+"直接加进当天。
  5. 每条地点可以标"还没去 / 已去过"，跟"有没有被排进过行程"是两件独立的事。
删除收藏清单里的地点，不影响已经排进行程里的那些行程项——它们各自保留了自己的名字和坐标。

汇率簿是干吗的

提前记好换汇的汇率，之后用外币记账直接选，不用每次都自己拿计算器算。

入口
记账 · 共 4 笔 簿
"记账"tab标题右边、写着"簿"字的小方块——没有图标，容易漏看
汇率簿 + 新增
JPY → MYR
出发前网上换的现金0.0296
手动输入 · 最近用于 2026/8/21
当地刷卡（银行汇率）0.0301
API参考值 · 最近用于 2026/8/21
编辑汇率只影响之后新记的账，不会改动过去已保存的记录金额。

具体步骤

  1. 从记账页点右上角写着"簿"字的按钮进入汇率簿，点"新增"，可以按当前汇率参考值直接采用，或者手动输入你实际换到的汇率（比如现金换汇跟银行刷卡汇率不一样）。
  2. 同一个货币对可以记不止一条——比如"出发前换的现金"和"当地刷卡"两种汇率分开记，记账时按实际情况挑对的那条。
  3. 记外币账目时，直接从这里选一条汇率，金额自动按汇率换算成本位币，不用自己算。
  4. 如果一笔开销的钱其实来自不止一批换汇（比如一部分现金一部分卡），可以在记账时拆开选多条汇率分别计入。
  5. 不再用的汇率可以"归档"（不会删除历史数据，只是不再出现在常用列表里）。
汇率簿里的每条记录会显示"用过几次"，方便看出哪种换汇方式实际用得最多。

具体步骤

  1. 导出与分享这一组：点导出行程右边的EXCEL/JSON/CSV任一个格式——Excel是明细+汇总两个sheet；JSON方便喂给AI工具写游记文案、剪短视频脚本；CSV摊平成表格方便导入其他工具。生成后手机会弹出系统分享面板，选"保存到文件"或者发给别人都行。
  2. 点分享设置，可以开一个只读链接，发给没有装APP的亲戚朋友，对方点开链接就能看行程和账目，不用注册登录，也改不了任何内容。
  3. 更多这一组是杂项功能：行程动态能看到团队里每个人最近记了什么账、加了什么行程安排；同步详情能看到哪些记录还没同步成功、卡在哪一步，卡住太久的还能手动放弃同步。
  4. 最下面还有"提交反馈"（用得不顺手的地方直接说）和"检查更新"（手机上感觉APP没更新到最新版时，点一下强制刷新）。
提醒：只读链接给出去之后，对方能看到的内容范围由"分享设置"里的选项决定，随时可以关掉链接收回访问权限。
