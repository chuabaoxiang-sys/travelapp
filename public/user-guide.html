三种情况，自动切换

  1. 出发前：一张"距离出发还有几天"的卡片，下面列出还没订好的行程项（比如还没订酒店、还没买票），再往下是"行程安排完成了几天""想去的地点里还有几个没排进去"这类准备进度。
  2. 途中：跟原来"记账"页顶部一样的"今天还能花/今天已花"大数字，加上今天接下来还没做的安排（点了直接去对应那天），再加上"家里刚才"——家人最近记的账、加的行程、结的账，一眼看到别人也在动这份行程。
  3. 回家后：整趟的总结——花了多少、几天几人、人均多少、钱花在哪几类、最贵的一天、每个人垫付/应分摊多少，还没结清的账会单独标出来提醒去结算。这其实就是原来"旅程回顾"的内容，现在不用去"更多"里找，回家后一进APP就是它。
行程还没填出发/返程日期时，会按"出发前"处理——先当成"准备阶段"来用。
第一次打开、还没建过任何行程时，"我的行程"页会多一行"先看使用指南"的链接。新建行程时可以选本位币（默认马币，也能改成新币/人民币/美元等），整趟行程的花费都按这个折算——已经建好的行程本位币暂时还不能改。

具体步骤

  1. 行程页顶部有三个视图可以切换：时间线（按天逐条看）、日历（一个月看全貌，日期下面顺带显示当天花了多少）、地图（每天的行程点用不同颜色标出来，点上面的日期图例还能只看那天的路线——图例可以左右滑动，行程天数多也不占地方）。
  2. 先在上面横向选一个日期，再点底部悬浮的紫色"+"按钮（在日历/地图视图点也会自动切回时间线）——弹出一张从下往上滑出的卡片，跟"记一笔"是同一个样式；填时间、要做什么、地点（可以搜索或直接贴Google Maps链接），换日期/从想去的地点选/备注/预约状态这几项收在"其他设置"里，点开才展开，顶栏"保存"随时够得到，不用往下滑。
  3. 点已有的卡片会原地展开成编辑框——"其他设置"默认是展开的（编辑时通常正是要改这几项），改完点顶栏"保存"，或者直接点卡片外面的空白处：标题填了就自动保存，标题还是空的就直接放弃，不会留下一条空行程项。
  4. 手机上用返回键也能收起编辑框，不会因此退出整个APP。
小技巧：紫色书签图标是"想去的地点"入口，规划行程时随时能从收藏清单里挑地方，不用重新搜索。

具体步骤

  1. 底部导航正中间紫色圆按钮"记一笔"——点开是个从下往上滑出的半屏卡片，不会整页盖住你原来在看的页面，点卡片外面暗掉的部分也能直接关掉。
  2. 先填金额，币种默认是本位币，旁边会有本位币+这趟行程设置里选好的"会用到的货币"（比如日本行程会有MYR/JPY两个），点一下就切换，不用手动打字；没提前选进去的生僻币种，点"其他"手动输入。选一个分类（餐饮/住宿/交通…）——这两项是真正每次都要你决定的，用外币记账时，只要汇率簿里有对应汇率，会自动换算成本位币。
  3. 阶段/日期/备注/付款人/关联行程/怎么分这几项默认收在"其他设置"这一行摘要里（比如"途中・今天・爸爸垫付・3人平均分摊"）——多数时候本来就是对的（自己付、今天、全家平摊），不用每次都点开确认一遍。
  4. 这次不是默认情况（比如别人垫付的、要跨天摊、要挂到具体行程项），点"改"，卡片原地长高，展开成跟以前一样的完整表单：怎么分可以选"大家分摊"（平均或自定义金额）还是"个人开销"；关联行程能把这笔账跟具体某个行程项绑在一起。改完点"收起"卡片会缩回去，但改动都保留着。
  5. 编辑一笔已经记好的账目时，"其他设置"会自动展开——已经记好的账目往往就是有什么地方不是默认值，不该被折叠挡住。
带小数的金额（比如509.60）现在会照实显示两位小数，不会被简化成整数——不用担心看着像存错了。

具体步骤

  1. 账目页切到"结算"这一段，顶部"结算建议"会自动算出最少的转账笔数——不是每个人两两互转，而是合并成最少几笔，就能让大家都不亏不赚。
  2. 点"去结算"，展开的表单可以填结清金额（支持部分结清，比如先还一半）、日期、备注（比如"现金"还是"转账"）。
  3. 确认对方已经收到钱之后，点"确认已结清"，这笔就会从"还剩几笔"里划掉。
  4. 如果想针对某一笔或者几笔具体的账目结算（而不是笼统的总账），用"按笔结算"——勾选一笔或多笔（可以跨不同的人），底部会显示"已选N笔·共多少钱"，点"结算选中的N笔"确认。只选1笔时金额可以改小做部分结清；一次选多笔时按各自还欠的全额结算，不能打折。清单里如果同时有好几组不同的"谁欠谁"，上面会多一排筛选（全部/某人→某人），点一下只看那一组，不用在一堆人的账里翻找。已经结清的账目会从这个清单消失，底部"查看已结清"点开能找回来，会标注是"按笔结算"还清的还是"预付款抵扣"的。
  5. 往下滚可以看"谁付了多少"——每个人垫付了多少、应该分摊多少，一目了然。
提醒：结清记录之后还能在下面的"结算记录"里找到、改金额/日期，或者撤销，不用担心手滑点错。
预付款：如果有人提前给了一大笔钱（还没产生任何账目），可以点"结算记录"旁边的"新增"直接记一笔——不需要先有欠款或账目。记完之后这个人的净额会显示对应余额，之后新记的具体账目会按日期从早到晚自动被这笔预付款抵扣，"按笔结算"清单里对应的账目会自动消失或者标注"已用预付款抵扣多少"，不用再手动核对、也不会重复结算。预付款还没花完的部分，会在"按笔结算"卡片顶部提示还剩多少。
注意：被"按笔结算"过的账目（哪怕只结了一部分），金额、汇率、怎么分、付款人这几项就不能再改、也不能删除了——避免跟已经记好的结算对不上。备注、分类、日期这些跟钱无关的还是能改。

具体步骤

  1. 从"账目"tab点"管理预算"，第一次打开会提示"还没设置整趟行程的总预算"——填个数字确认，圆环图就会跟着显示已用比例。
  2. 点"加分类预算"，可以单独给"餐饮""住宿"这些分类设上限，各自有独立的进度条。
  3. 记的每一笔账都会自动算进对应分类和总预算里，不用手动更新。
  4. 想改总预算，点"改总预算"；不想再追踪了，点垃圾桶图标删除（已经记的账不受影响）。
预算只是提醒自己，超支也不会锁住记账功能——该记还是能记，只是进度条会变红提醒一下。

具体步骤

  1. 入口有两处：顶层"我的行程"列表页右上角的胶囊按钮；或者进了具体某趟行程后，行程tab头部的紫色书签图标（不管切到时间线/日历/地图哪个视图都在）。
  2. 点"新增"，填地点名字（可以搜索定位，或者贴Google Maps链接）和备注。
  3. 安排行程时，"添加行程项"表单上方有"从想去的地点里选一个"，选一条会自动带上名字和坐标，不用重新搜索。
  4. 安排行程时，如果清单里有地点离当天已排的行程比较近，"想去的地点"书签图标上会出现数字角标；点进去，这些"附近想去"的地点会单独列在最上面，点"+"直接加进当天。
  5. 每条地点可以标"还没去 / 已去过"，跟"有没有被排进过行程"是两件独立的事。
删除收藏清单里的地点，不影响已经排进行程里的那些行程项——它们各自保留了自己的名字和坐标。

汇率簿是干吗的

提前记好换汇的汇率，之后用外币记账直接选，不用每次都自己拿计算器算。

入口
账目 · 共 4 笔 簿
"账目"tab标题右边、写着"簿"字的小方块——没有图标，容易漏看
汇率簿 + 新增
JPY → MYR
出发前网上换的现金0.0296
手动输入 · 最近用于 2026/8/21
当地刷卡（银行汇率）0.0301
API参考值 · 最近用于 2026/8/21
编辑汇率只影响之后新记的账，不会改动过去已保存的记录金额。

具体步骤

  1. 从账目页点右上角写着"簿"字的按钮进入汇率簿，点"新增"，可以按当前汇率参考值直接采用，或者手动输入你实际换到的汇率（比如现金换汇跟银行刷卡汇率不一样）。
  2. 同一个货币对可以记不止一条——比如"出发前换的现金"和"当地刷卡"两种汇率分开记，记账时按实际情况挑对的那条。
  3. 记外币账目时，直接从这里选一条汇率，金额自动按汇率换算成本位币，不用自己算。
  4. 如果一笔开销的钱其实来自不止一批换汇（比如一部分现金一部分卡），可以在记账时拆开选多条汇率分别计入。
  5. 不再用的汇率，从没被账目用过的可以直接"删除"；已经被账目用过的只能"归档"（不会删除历史数据，只是不再出现在常用列表里，删了会让那些账目找不到对应的汇率来源）。
汇率簿里的每条记录会显示"用过几次"，方便看出哪种换汇方式实际用得最多。

具体步骤

  1. 外观这一组：深色模式三选一——浅色/深色/跟随系统，选好了会记住，不用每次都靠手机系统判断。配色沿用同一套设计语言，大数字、汉字方块分类徽章这些都不变，只是换了颜色。
  2. 导出与分享这一组：点导出行程右边的EXCEL/JSON/CSV任一个格式——Excel是明细+汇总两个sheet；JSON方便喂给AI工具写游记文案、剪短视频脚本；CSV摊平成表格方便导入其他工具。生成后手机会弹出系统分享面板，选"保存到文件"或者发给别人都行。
  3. 点分享设置，可以开一个只读链接，发给没有装APP的亲戚朋友，对方点开链接就能看行程和账目，不用注册登录，也改不了任何内容。
  4. 更多这一组是杂项功能：同步详情能看到哪些记录还没同步成功、卡在哪一步，卡住太久的还能手动放弃同步。想看"家里谁记了什么账、加了什么行程安排"，去"概览"标签的"家里刚才"，点"查看全部"就是完整的动态列表——这个入口已经从"更多"搬过去了，因为在"概览"上顺手就能看到，不用绕一层。
  5. 最下面还有"提交反馈"（用得不顺手的地方直接说）和"检查更新"（手机上感觉APP没更新到最新版时，点一下强制刷新）。
提醒：只读链接给出去之后，对方能看到的内容范围由"分享设置"里的选项决定，随时可以关掉链接收回访问权限。
