# 小红书招募测试用户策略（讨论稿，尚未执行）

记录于 2026-08-13 的一轮讨论结果，供之后随时接着聊或调整——**这只是策略规划，还没有发布任何内容、没有改任何代码**。

## 背景与目标

- 现状：「旅记」目前只有自己家人 + 少数手动邀请的团队在用，还没做过任何公开招募。
- 需求：最缺真实测试用户，想通过自媒体（小红书）招揽。
- 成功标准：**少而精**——5个左右愿意认真用完一趟旅行并给反馈的人，不是追求曝光量或注册数。

## 关键决策

| 项目 | 决定 |
|---|---|
| 平台 | 小红书 |
| 账号起点 | 完全零粉丝新号 |
| 目标画像 | 和自己相似的马来西亚华人家庭 |
| 内容量 | 2-3篇（不是最初设想的1篇），用于对比测试不同角度 |

| 建户方式 | 沿用现成的 [邀请新团队流程.md](邀请新团队流程.md)，私信拿到邮箱后照走这套已验证流程 |
| 陌生人访问架构 | 不改——继续手动建户（邮箱邀请+RLS隔离）。网站已经取消整站密码墙（2026-08-16），陌生人可以直接打开网址看到登录界面，但没被邀请的邮箱进不去任何数据，对招募反而更友好，减少了一道门槛。自媒体只负责引流+收集意向 |

## 冷启动现实评估（关键）

零粉丝新号 + 只发一篇帖子，大概率**达不到**5个精准家庭这个目标——不是执行细节问题，是曝光结构性不够（新号权重低，单篇曝光通常只有几十到几百，真正落进"马来西亚华人+旅行+多人记账痛点"这个窄交集的人可能只有个位数）。因此调整为2-3篇，且需要认知到：

- 小红书对新号的推荐机制是分层流量池——早期数据（完播/停留、点赞/评论/收藏/分享）不达标，笔记很难进入更大曝光层，这是结构性的,不是内容写得好就能绕过。
- **收藏率/搜索沉淀**可能比赌算法推荐更现实——笔记标题/正文包含目标用户真的会搜的词（如"家庭旅行记账""大马家庭旅游"），有助于笔记长期留在搜索结果里被动获客。
- 纯产品宣传类内容容易被判定软广而限流，痛点/故事切入通常比直接推广表现更好。
- 站外私域导流（大马华人旅游群/FB群，人工制造前几十个互动）对触发早期流量池判定有实际帮助,是零粉丝账号少有的可控杠杆。
- 长期看，小红书笔记更适合定位成"长尾搜索入口+信任背书"，短期5人目标真正的来源可能还是私域（朋友介绍、已有群组直接私信匹配的人）。

## 内容角度（策略概念，还没写文案）

计划测试的角度组合：**A + C，视数据决定是否加发 D**

- **A. 痛点吐槽型**（先发，作为账号"温度计"）：具体窘境式共鸣（如"一家人出国对账对到吵架"），App结尾轻带出。评论率通常高，但共鸣要具体不能泛。
- **C. 身份认同型**（必测）：直接锁定"大马华人家庭"视角，本地化场景切入。触达面窄但精准度最高，是唯一直接验证"零粉丝单篇能不能精准打到目标人群"的角度。
- **D. 对比/Before-After型**（可选，视A/C数据决定）：以前用Excel/群里报账 vs 现在的对比。点击率钩子强，但偏产品展示，软广风险相对高。
- B（干货/攻略型）不单独占名额,收藏价值可以自然融入A或C的文案结尾。

## 发布节奏

- 顺序：A → C → （视数据）D
- 间隔：每篇约一周，让上一篇数据成熟到可比较的程度
- 固定发布时段：晚8-10点/周末，减少变量方便横向比较三篇表现
- 每篇发完先看数据（曝光、精准画像的人是否留言）,再决定下一篇是否按计划发或调整角度
