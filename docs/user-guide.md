# 旅记 使用说明

「旅记」是给家人用的旅行行程 + 账目记录APP，可以记录每趟旅行的行程安排，以及旅行前后、途中的所有开销，并且自动处理多币种汇率、按人分摊/结算的问题。

> ⚠️ **重要提醒（请务必先看这一段）**：目前APP的所有数据都只存在**你当前使用的这台手机/浏览器本地**，没有连接任何云端服务器，也就是说：
> - **不同设备之间看不到彼此的数据**——爸爸手机上记的账，妈妈手机上是看不到的，除非将来接上云端同步（尚未开放）
> - **清除浏览器数据、换手机、重装APP，本地记录会永久丢失**，没有云端备份
> - 目前**没有"只读分享链接"功能能实际对外生效**（界面上暂时也没做这个入口），要等云端同步做好才有意义
>
> 简单说：**现阶段建议全家人共用同一台设备/同一个浏览器记账**（比如放在一部大家都能拿到的手机或平板上），或者定期手动导出Excel/JSON备份（见下方"导出与分享"一节），避免数据意外丢失。

---

## 1. 首次打开

打开APP后会先问"你是谁"——从已有的家庭成员里选一个身份，或者输入姓名新增一个。之后你记的每一笔账、每一次结算，都会算在这个身份名下。**不需要密码**，选好名字就能直接使用。

## 2. 建立一趟新行程

进入"我的行程"页面后点"＋新建行程"：
- 行程名称（比如「2026日本关西家族游」）
- 出发/返程日期（可以先不填，等确定了再回来补，行程状态会显示"规划中"）
- 目的地国家（可选，多选）——设置后，之后在行程里搜地点时会自动限制在这些国家范围内，避免搜出同名但相隔很远的地方

行程建好后随时可以点"✎编辑"改名称/日期/目的地国家，或者点"🗑删除"整趟删掉（会连同这趟行程的所有行程记录和账目一起删除，操作前会二次确认）。

## 3. 行程记录（底部"行程"标签）

设置了起止日期后，行程页会按天列出日期条，点某一天可以"＋添加行程项"，填时间、标题、地点。地点支持搜索定位（会在目的地国家范围内搜索），选中后行程会在"地图"视图里显示对应图钉。

- **时间线视图**：按时间顺序列出当天所有安排，新增/编辑后会自动按时间重新排序，不用手动调整顺序
- **日历视图**：按月历方式查看整趟行程，日期格子下会显示当天已经花了多少钱
- **地图视图**：把所有带地点的行程项标在地图上，点图钉能看到当天第几个安排

点某个行程项卡片可以原地编辑或删除。

## 4. 记账（底部"记账"标签 + 右下角"＋"按钮）

点右下角紫色圆形"＋"按钮打开记一笔的面板：

1. **出行前/途中**：先选是出行前的花费（机票/保险/签证/酒店预付）还是途中的花费（餐饮/交通/购物/门票/住宿现付/杂项），下方分类会跟着变
2. **金额与币种**：如果币种和行程本位币不一样，会出现"选择汇率"区域
3. **汇率簿**（多币种记账的核心功能）：同一种外币在同一趟行程里用过的汇率会变成可以直接点的标签（比如"现金汇率""信用卡汇率"），点一下就套用，不用每次重新输入；第一次用某个汇率时点"＋新汇率"，系统会自动去查一个参考汇率帮你预填，但可以随意修改。点"簿"图标（记账页顶部）可以进入汇率簿管理页，查看/编辑/归档已经用过的汇率标签——**编辑汇率只影响以后新记的账，不会改动过去已经记好的账目金额**
4. **付款人**：谁实际掏的钱
5. **这笔怎么算**：
   - **大家分摊**：勾选参与分摊的人，金额会平均分给这些人（分不尽的几分钱会给第一个人，保证加总不会有误差）
   - **个人开销**：这笔算付款人自己的开销，不会出现在"分账"页面的结算里（比如某人自己买的纪念品）

记好的每一笔账都可以点开原地编辑或删除。

## 5. 预算（底部"预算"标签）

可以设置整趟行程的总预算，也可以按分类单独设预算（比如"餐饮不超过RM2000"）。超支的分类会自动排到列表最前面并显示红色警示。总预算和分类预算都可以随时修改或删除。

## 6. 分账/结算（底部"分账"标签）

这个页面会自动算出"谁该收谁的钱"，用的是最简结算算法（尽量用最少的转账笔数把账结清）：

- **结算建议**：显示还没结清的转账建议（比如"阿明→爸爸 RM80"）
- 点"去结算"可以**记录一笔实际的结款**——支持部分结清（比如先还一半），填好金额/日期/备注后确认
- 已经结过的款项会出现在"结算记录"里，可以随时编辑或删除（删除会撤销这笔结算，欠款金额自动恢复）
- 每个人的卡片会显示"应收/应付/已结清"，以及垫付、应分摊、已还/已收的明细

## 7. 导出与分享（行程页头部"⋯"按钮）

点行程切换按钮旁边的"⋯"图标，可以：
- **导出Excel**：一份工作簿里有"明细"（行程和账目逐条列出）和"汇总"（按天/按分类/按人统计好）两个sheet
- **导出JSON**：适合丢给AI工具（比如生成游记文案、短视频脚本）
- **导出CSV**：摊平成表格，方便导入其他工具

点导出后，如果你的手机/浏览器支持，会直接弹出系统的分享面板（微信、WhatsApp、邮件、AirDrop等），选一个就能直接发送，不需要先下载到相册/文件再手动找出来发；如果当前浏览器不支持，会退回成普通下载。

> 目前只做到"导出后手动分享给别人"这一步。前面提到的"生成一个链接，别人点开就能看行程"的功能还没做（因为要等云端同步先接上）。

## 8. 离线使用 / 安装到主屏幕

「旅记」是一个PWA（渐进式网页应用），可以像真正的APP一样安装到手机主屏幕：
- **Android/Chrome**：打开APP后如果出现"把旅记安装到主屏幕"的提示条，点"安装"即可；没出现的话，也可以在浏览器菜单里找"安装应用"
- **iOS/Safari**：iOS不支持自动弹出安装提示，需要手动操作——点底部分享图标 → 「添加到主屏幕」

安装后即使没有网络也能正常打开使用（行程/记账/预算/分账所有功能都能离线操作），顶部会有一个小圆点显示同步状态（目前"待同步"数字只会累积，不会自动清零，因为云端同步还没接上，见文首提醒）。

## 9. 提交反馈

在"⋯"面板里点"提交反馈"，选一个分类（问题反馈/功能建议/其他）、写下内容就能提交，下方会看到所有人提交过的反馈记录，也可以编辑或删除自己写错的内容。

反馈目前也是先存在本地——跟其他数据一样，等云端同步接上后会自动汇总到一起，方便统一整理哪些该优先改进。现阶段如果全家共用同一台设备记账，其实已经能看到彼此的反馈了。

## 常见问题

**Q: 我删错了一笔账/一条结算记录怎么办？**
A: 目前没有"撤销"功能，删除前都会有二次确认弹窗，请确认清楚再点删除。

**Q: 汇率填错了，已经保存的账目金额会跟着变吗？**
A: 不会。汇率簿里的汇率被修改后，只影响以后新记的账；过去已经保存的账目金额是当时汇率的"快照"，不会被追溯修改。

**Q: 换了手机，之前的记录还在吗？**
A: 不在。目前数据只存在原来那台设备的浏览器里，换设备前请先导出Excel/JSON做备份（见上方"导出与分享"）。
