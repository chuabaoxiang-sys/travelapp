# 宣传素材截图清单

用途：给未来所有宣传（小红书招募、产品介绍、应用商店素材等）用的截图/录屏总清单。

## 怎么重新生成

```bash
npm run dev   # 先把本地开发服务器跑起来，端口5173
node marketing-assets/scripts/capture-marketing-shots.cjs light
node marketing-assets/scripts/capture-marketing-shots.cjs dark
```

用的是项目自带的"本地测试模式"（登录页那个按钮，仅 `import.meta.env.DEV` 生效，不碰真实账号/Supabase）+ `src/dev/localTestSeed.ts` 里的三趟种子行程（上海未出行/韩国出行中/瑞士已回来，一家三口：爸爸/妈妈/阿灰），跟 `scripts/capture-tutorial-shots.cjs`（教程截图）是同一套底层数据，保证看着真实、不含"Test"占位字样。

**设计改版后要重拍**：直接重新跑上面两条命令，文件名不变、会原地覆盖，不用手动对照哪张过期了。

命名规则：文件名不带序号——一个分类目录下的文件名本身就是说明，深色版加 `-dark` 后缀。

字段说明：
- **状态**：脚本自动生成 / 待补拍（需要真机或额外交互）/ 无对应界面（数据库里有表但APP没做用户可见界面）
